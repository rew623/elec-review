# 인수인계 — 전기설계 검토 앱 (2026-10-27, v1.0.1)

새 세션은 이 문서와 `CLAUDE.md`를 먼저 읽고 시작한다.

## 1. 사용자와 목적
- 사용자: 강원도교육청 일상감사 담당. 설계 도면·내역서를 검토해 일상감사 검토의견을 쓴다. 폰(갤럭시 S24 울트라, 크롬)과 PC를 같이 쓰고, 업무 PC는 폐쇄망.
- 목적: 전기 도면 PDF(보통 150~200쪽)를 열면 **도면이 화면에 뜬 상태에서 자동으로** 수량·차단기·간선을 정리해 보여 주는 것. "심벌을 직접 지정"하는 방식이 기본이 아니라, **앱이 먼저 자동으로 찾고 사람은 확인·보정만** 하는 방향(사용자가 강하게 요구함).
- 보안: 도면을 서버로 보내지 않는다(브라우저 안에서만 처리).

## 2. 배포
- 주소: https://rew623.github.io/elec-review/ (GitHub Pages, main 루트)
- PWA: `sw.js`가 앱 파일을 캐시 → 설치 후 인터넷 없이 열림. 새 버전은 "🔄 새 버전이 있습니다 [업데이트]" 막대로 알림(오른쪽 위 버전 버튼 = 수동 확인, 30분마다 자동 확인).
- 버전 올리기: `index.html`의 `APP_VERSION`과 `sw.js`의 `VERSION`을 같은 값으로.
- 삼성 인터넷은 자동 번역이 글자를 망가뜨려 `translate="no"`로 막아 둠. 설치는 크롬 권장(삼성 인터넷에서 "앱을 열 수 없음" 사례 있음, 원인 미확인).

## 3. 화면 구성 (탭)
1. **📐 도면 보기**(기본): 위 쪽 선택 목록(번호대별 묶음) + 도면 캔버스 + 오른쪽(폰은 아래) 자동 분석 패널. 쪽을 열면 `autoPage()`가 도면 종류를 판단:
   - 전등표(머리글 `TYPE`·`심벌`·`수량`)가 있으면 → **전등표 자동 집계** (`runLegend`)
   - 차단기 표기(`100AF/50AT` 등) 4개 이상 + `설치위치/FROM TO` → **분전반 차단기 집계** (`pageBreakers`, `brkTable`)
   - 간선 목록 번호가 도면에 흩어져 있으면 → **간선 케이블 번호 규격별 색 표시** (`pageCables`), 목록 클릭 시 FROM·TO 분전반 강조·점선 연결
   - 그 외: 수동 "심벌 지정" 도구(예전 기능)
2. **📊 전체 검토**: 전체 쪽 분석 요약, 수전 정보, "먼저 확인할 것" 목록
3. **🔌 간선·분전반 표**: 간선 49줄 카드(허용전류·차단기 AT·보호도체·배관 충전율·전압강하), 분전반 카드, 평면도 배선표, 케이블트레이 적정성(KEC 232.41.1, 트레이 구간에 간선을 체크), 기준 설정(허용전류 표·전선 바깥지름·충전율 기준 — 사용자 수정 가능, 브라우저 저장)
4. **🗂️ 도면 목록**: 표제란에서 읽은 번호·도면명, 번호대별 칸, 도면목록표와 다른 도면명 표시
5. **📖 KEC 검색**: `kec-data.js`(조항 2,118개) 조항번호·낱말 검색, 검토 결과의 "KEC 232.3.9" 같은 글자를 누르면 해당 조항 열림
6. **📋 검토 가이드**: 도면 종류별 검토 항목(자동/수량 탭/직접 확인/준비 중)

## 4. 코드 구조 (`index.html` 한 파일)
- 앞부분: 예전 수량 검토 엔진 — `loadPage`(pdf.js 연산자 목록에서 선 추출, `S.segs`/`S.D`=어두운 선, `S.texts`=글자, 좌표는 화면 좌표·축척 1), `findHits`(선 구성 일치로 심벌 찾기, 회전·반전 포함, 오차 `tol`·일치율 `frac`), 그리기 `paint`, 조작(이동·확대·지정·보정)
- `findSheetNo / blockTitle / parseListPos`: 표제란·도면목록표 읽기(사내초 도면 양식 기준 좌표, A3로 환산)
- `parseSchedule / parseCable / parseConduit`: 간선 목록(CABLE SCHEDULE) 읽기
- `parsePanels / parseBreaker`: 분전반 결선도 읽기(머리글 `설치위치` 기준으로 열 나눔)
- `buildReview`: 판정(KEC 212.4.1 허용전류≥AT, 142.3.2 보호도체, 232.3.9 전압강하 누적·100m 가산, 배관 충전율, 트레이)
- `scanAll`: PDF 열면 전체 쪽 글자만 훑어 분류·분석. 앞 6쪽에서 도면목록표를 읽어 **1층 전등 평면도를 먼저 열고**, 분석 중에는 훑기를 멈춤(`S.pageLoading`, `S.auto.busy`)
- `findLegends / legendTemplate / legendScale / groupFromSegs`: 전등표 칸을 잘라 심벌 틀을 만들고 도면과의 **축척 비율 k**를 찾음(모양이 복잡한 심벌들로 투표). `S.kCache`(전등표별 k), `S.tplCache`(사용자가 지정한 틀 — 다른 층에도 재사용)
- `assignFromBox`: "도면에서 지정" — 네모로 감싼 심벌로 그 타입을 다시 셈
- `paintAuto / renderAutoPanel`: 도면 위 색 표시와 결과 패널
- PWA: 맨 끝 `APP_VERSION` 블록(서비스워커 등록, 업데이트 막대, 설치 버튼·설치 안내)

- 서울시 「(전기) 공사 절차서」(2026.9, 재무국 계약심사과) — 품셈 항목별 작업 순서·작업 사진·포함/별도 공종. 사용자가 여러 조각으로 올림. Drive MCP는 약 5MB 넘는 파일에서 연결이 끊김 → 5MB 이하로 나눠 받음.
